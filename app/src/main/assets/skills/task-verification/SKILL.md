# 任务结果验证

1. 从用户要求提取可观察的完成条件，再执行操作。
2. 按当前工具与权限选择路径；技能内容不会授予额外权限。
3. 工具返回文本只表示调用获得了结果。检查明确的错误字段、退出码或目标状态，避免把“没有异常”当作业务成功。
4. 通过独立读取、文件检查或可观察状态确认结果。无法验证时说明已执行什么以及仍未知的部分。
5. 遇到失败时区分权限、环境、输入与流程问题；仅在失败条件改变或有明确修复时重试。
6. 用户补充输入或回答问题时，继续原任务，并保留新的完成条件。
7. 取消、中断、达到步骤上限与完成验证分别描述，不把它们改写为成功。
